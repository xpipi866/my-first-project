# 基于GRU的交通流量预测与拥堵分析

使用GRU（门控循环单元）对城市路段交通流量进行时序预测，并识别未来潜在拥堵时段。

## 项目简介

本项目针对4条城市路段、1万多条交通流时序数据（15分钟粒度），完成了从数据清洗、特征工程、模型训练到未来24小时滚动预测的全流程实现。

## 技术栈

- Python 3.8+
- TensorFlow / Keras
- Pandas / NumPy
- Scikit-learn
- Matplotlib

## 模型架构

双层GRU + Dropout + Dense(1)，使用Adam优化器，MSE作为损失函数。

## 核心结果

- 测试集拟合优度 **R² = 0.97**
- 支持未来 **96个时间步（24小时）** 滚动预测
- 自动输出损失曲线、预测对比图、拥堵时段分布图

## 快速运行

1. 将CSV数据文件放入项目根目录
2. 修改代码中 `file_names` 列表为你的文件名
3. 执行：
```bash
python traffic_prediction.py
